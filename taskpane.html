SETTINGS & HELP
No account required
ZYVORA Tools works directly inside Excel.There is no Sign Up, Login, password, or ZYVORA account system in this build.
G
Optional Google connectionNot connected
Google access is optional and uses Google's OAuth consent. Configure your own OAuth Web client ID in taskpane.js. No Google password is handled by ZYVORA.
Install
  1. Publish this repository with GitHub Pages.
  2. Upload manifest.xml to Excel when sideloading is available.
  3. Open ZYVORA Tools from the custom Ribbon tab.
